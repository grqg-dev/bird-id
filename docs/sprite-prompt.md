# Bird sprite sheet — Gemini prompts

Two **5×5 grids** (25 birds each), **16-bit pixel art** style. Copy-paste one
prompt at a time into Gemini. Square output, 1:1 aspect ratio.

Style: retro 16-bit game sprite sheet — crisp pixel art, limited palette, clean
silhouettes, no anti-aliasing blur. Each bird readable at small size. Attach your
style reference image if you have one.

---

```
no text, no labels, no captions, no species names, no numbers, no watermark,
no signature, no border or frame, no multiple birds in one cell, no duplicate
birds, no humans, no hands, no cage, no background scenery, no gradient
background, not blurry, not photorealistic, not watercolor, not 3D, not smooth
```
